# AI Support Ticket Intelligence Dashboard

An AI-powered customer support analytics dashboard built with Streamlit.

The application analyses support ticket data to uncover customer sentiment, recurring issues, urgent cases, and chatbot automation opportunities.

## Features

- Upload and analyse support ticket CSV data
- Automatic ticket categorisation
- AI-assisted sentiment detection
- Urgent ticket identification
- Automation opportunity scoring
- Interactive visual analytics dashboard

## Tech Stack

- Python
- Pandas
- Streamlit
- Plotly
- OpenAI API
